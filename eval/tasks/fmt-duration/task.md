# 新增时长格式化函数 formatDuration

`src/application/format.ts` 是各报告视图共用的通俗措辞格式化模块。请在其中新增并导出一个纯函数，把毫秒时长渲染成简短的中文表述。

## 对外接口

```ts
export function formatDuration(ms: number): string
```

## 行为

1. 输入校验：`ms` 不是有限数（`NaN`、`Infinity`、`-Infinity`）或小于 0 时抛出 `RangeError`（消息自拟）。
2. 先把 `ms` 四舍五入到整数（`Math.round`），下面的规则都作用于取整后的值 `t`。
3. `t < 1000`：`"<t> 毫秒"`，例如 `0` → `"0 毫秒"`，`999` → `"999 毫秒"`。
4. `1000 ≤ t < 60000`：秒数保留一位小数，**向下截断而不是四舍五入**，小数位为 0 也保留，格式 `"<整数秒>.<十分位> 秒"`。例如 `1000` → `"1.0 秒"`，`1500` → `"1.5 秒"`，`59999` → `"59.9 秒"`。
5. `60000 ≤ t < 3600000`：`"<分> 分 <秒> 秒"`，两者都向下取整，例如 `60000` → `"1 分 0 秒"`，`125400` → `"2 分 5 秒"`。
6. `t ≥ 3600000`：`"<小时> 小时 <分> 分"`，两者都向下取整，秒被舍去；小时数不封顶，例如 `3600000` → `"1 小时 0 分"`，`7384000` → `"2 小时 3 分"`，`90000000` → `"25 小时 0 分"`。
7. 取整会跨档：`999.6` 取整为 `1000`，结果是 `"1.0 秒"`。

数字与单位之间用一个半角空格分隔，不加其他前后缀。
