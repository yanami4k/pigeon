## 三、实现的计算

### 主判据（1.1–1.6、222）

- 每步得分 = 要做到的用例中通过的条数 ÷ 要做到的总数；要做到的为零的步得分记空，不进主判据分母，报告单列题号。
- ȳ(c, i) 为该格该题已有各遍的等权平均；某遍缺失即按其余遍平均。有效题：要做到的不为零、四格各至少一遍有效结果；四格中任一格一遍都没有的题列为缺失（给出题号与缺哪几格）；缺失题超过有效题的 10% 时报告置顶注明、结论降格为探索性。给出全部题号时，完全没有结果行的题也列为缺失。
- 推送差 dP(i) = [ȳ(10) + ȳ(11)]/2 − [ȳ(00) + ȳ(01)]/2；检索差 dS(i) = [ȳ(01) + ȳ(11)]/2 − [ȳ(00) + ȳ(10)]/2；交互 dPS(i) = [ȳ(11) − ȳ(10)] − [ȳ(01) − ȳ(00)]。效应估计为有效题上的等权平均。
- 主检验：各题差的正负号随机翻转 100,000 次，翻转后平均差绝对值不小于实测平均差绝对值的比例即双侧 p 值（照计划原文，不加 1 修正）。
- Holm 两步：较小的 p ≤ 0.025 才判显著并进入第 2 步，较大的 p ≤ 0.05 判显著；两个 p 相等时取推送为第 1 步；某个效应没有有效题时按不显著处理，另一个仍按第 1 步门槛 0.025 判。
- 95% 置信区间：按题有放回重抽 10,000 次，取 2.5% 与 97.5% 分位数。效应量：百分点、dz = mean(d) / sd(d)（样本标准差），另给相对 00 格平均得分的变化比例。
- 稳健性对照：score ~ 推 + 拉 + 推×拉 + (1｜题) + (1｜流)，流 = 格 × 遍，推、拉按 ±0.5 编码（系数即另一因素两水平上的平均效应，与 DP、DS 同义），REML 拟合；对其两个 p 值同样做 Holm 两步。方向（符号）或 Holm 显著性与主检验不一致即判"结论对建模方式敏感"；拟合失败时记录原因、不作比较；未收敛时照常比较，报告注明系数与 p 值仅供参考。
- 种子：置换 202609271、自助法 202609272，每次调用都由种子新建生成器，调用顺序不影响结果。

### 次要判据（第 2 节，一律标探索性）

- 做成与否：每格做成率；推、拉效应按 1.3 把得分换成做成与否，给区间与未校正 p 值。
- 不许挂的失败：每格合计、每步平均、有失败的步数（全部有结果的步）；推、拉效应按 1.3（有效题）。
- 学习曲线：t(i) 在全部题上按时间排位（第 1 题 0、最后一题 1，含要做到的为零与缺失的题），dP(i) 对 t(i) 最小二乘斜率，按题自助法给区间；后半段差 = 后一半题平均 − 前一半题平均（有效题按时间排序，奇数时中间一题不计）；检索同理；另给四格原始得分的居中滑动平均（窗口 9 题）。
- 交互效应：dPS 平均与区间。
- 效率：轮数、输入 token（未命中 / 命中）、输出 token、墙钟、花费，复盘的轮数、墙钟与花费单列；各格中位数与 90 分位；推、拉效应为按题配对差的中位数。
- 各格对最简 agent：ȳ(c, i) − y(M, i, 1) 在有效题且最简 agent 有结果的题上的平均与按题自助法区间，注明最简 agent 只有一遍。
- 记忆使用：推送两格的开工时记忆字符数 / 字节数 / 条目数（平均、中位、最大）与 mem_ 计数（合计、每步平均）；检索两格的 search_ 计数。

### 设计灵敏度与第 3 遍（3.7、224）

- v：各格同题两遍之差 e 的方差的一半，多格合并时按各格以自身均值为中心的合并方差（自由度相加）；只用两遍都有有效得分的题。
- 校准：v 由 01、11 两格合并；d(i) = ȳ(11, i) − ȳ(01, i)（只用两格两遍都齐的题），τ² = max(0, 样本方差 − v)；MDE = (2.24 + 0.84) × √((τ² + v/R) / n) × 1.3，按 R = 2、3 各算，n 由参数给出（缺省 89，报告注明来源）。
- 第 3 遍：四格都恰好两遍时判定。v 由四格合并；τ² = max(0, 两遍平均的 dP(i) 样本方差 − v/2)，检索差同法；降低比例 = 1 − √((τ² + v/3)/(τ² + v/2))，取两者中较大者；B = 650 − 四格已花 − 最简 agent 已花（尚未跑时须以参数给出预留 C_M，否则不判定）；C3 = 四格前两遍实际花费 ÷ 2 × 1.1；B ≥ C3 且降低比例 ≥ 10% 才补。每步花费含复盘。全程不用任何差值的均值。
- 正式报告里的 MDE = 3.08 × sd(dP) / √n，不乘 k。

### 校准取值规则（第 3 节）

- 3.1 做成率：01 格两遍合计，30% ≤ 做成率 ≤ 70% 留下、> 70% 换仓、< 30% 记"低于门槛、处理另定"；两遍相差超过 20 个百分点注明。
- 3.2 花费：c01、c11、cM 为每步平均花费（含复盘）；C_pass = 89 × (2c01 + 2c11) × 1.1，C_M = 89 × cM × 1.1，C_base = 2C_pass + C_M；≤ 520 按计划开跑、≤ 650 开跑但第 3 遍基本无望、> 650 交项目负责人裁决。结果行有折回非高峰价的花费列时用该列，否则用实测花费并在报告注明。
- 3.3 上下文峰值：Pigeon 两格每步单次请求输入峰值的中位、90 分位、最大；给出压缩触发点时统计超过其 80% 的步数。
- 3.4 每步预算：只看 Pigeon 两格；轮数 = 最大 × 1.5 向上取整到 10、不低于 150；墙钟 = 最大 × 1.5 向上取整到 5 分钟、不低于 30；有步轮数 ≥ 300、墙钟 ≥ 60 分钟或结果行标记撞上限，则取 600 轮、120 分钟；超过 600 轮或 120 分钟封顶并报告。
- 3.5 记忆上限：11 格每遍的每步平均增长 =（最后一个开工时大小 − 第一个）÷ 两者相隔的步数；两遍增长相差超过一倍取较快一遍，否则取平均；× 30 后向上取整到 1,000，再夹在 2,200 到 12,000 之间。结果行没有字符数时退用字节数并注明。
- 3.6 复盘上限：轮数 = 最大 × 1.5 向上取整到 5、不低于 20；墙钟 = 最大 × 1.5 向上取整到 1 分钟、不低于 5；有复盘轮数 ≥ 40 或墙钟 ≥ 10 分钟或结果行标记撞上限，则取 80 轮、20 分钟。
- 抽题：可抽的题（要做到的不为零）去重后按题号升序排成总体，random.Random(20260927).sample(总体, 15) 后按时间排序；给出可抽题号时核对结果中的题是否正是这 15 道。
- 门槛比较一律带 1e-9 的容差，端点按规则算在哪边就在哪边（例如无推送两格平均得分为有理数平均时 0.9 会被浮点误差算成 0.8999999…）。

### 报告措辞（第 4 节）

按 Holm 显著性与估计方向选句式：测出为正、测出为负、未测出（附正式报告的 MDE）；无推送两格平均得分 ≥ 90% 时在推送效果的"未测出"句后加"（基线触顶）"；某效应与混合模型不一致时句末加"结论对建模方式敏感，见稳健性分析。"；缺失题超过 10% 时置顶降格说明。检索效果的主语为"可检索历史会话"。

## 五、模拟检验

模拟模型：y(c, i, r) = 0.5 + a_i + (推送效果 + b_i)·p_c + 检索效果·s_c + ε，p_c、s_c 取 ±0.5，a_i ~ N(0, 0.15²)，b_i ~ N(0, τ²)，ε ~ N(0, v)，与 3.7 的方差模型一致（单遍时 dP 的噪声方差为 v）。每次模拟用 2,000 次翻转、500 次重抽（只影响 p 值与区间的蒙特卡洛精度）。

| 检验 | 设置 | 结果 | 期望 |
|---|---|---|---|
| 零效果误报率 | 89 题、2 遍、v = 0.02、τ² = 0.005，1000 次 | 推送 p ≤ 0.05 的比例 0.047；Holm 下两效应任一显著 0.053 | 约 0.05 |
| 零效果误报率（有界离散得分） | 60 题、2 遍、每步 5 条用例、得分为通过比例，600 次 | 0.045 | 约 0.05 |
| 检出率 | 89 题、2 遍、τ² = 0.01、v = 0.0269（使 5 个点正好是不乘 k 的 MDE），真实效果 5 个点，400 次 | 0.782 | 公式 0.800 |
| 检出率 | 同上，真实效果 3 个点 | 0.335 | 公式 0.348 |
| 区间覆盖率 | 89 题、2 遍、效果 4 个点，400 次 | 0.945 | 0.95 |

公式预测为 Φ(效果 / SE − 2.24)，SE = √((τ² + v/R)/n)，不乘 k（模拟里没有同一条流内的连带影响）。判定容差：误报率 ±2.1 个百分点（离散得分 ±2.7），检出率 ±8 个百分点，覆盖率 0.91–0.985。

## 六、边界用例

- 主判据：F 为空的题不进分母、不算缺失、不使结论降格；得分即使给了也置空；某格某遍缺失按其余遍；某格整题无结果则该题列为缺失；判题故障（行在而得分空）按缺失；缺失 1/10 不降格、2/9 降格；给出全部题号时无结果行的题列为缺失；重复行取最后一条；只有一遍；无推送两格正好 0.90 为触顶、0.8995 不触顶。
- 统计原语：符号翻转与 2^n 穷举一致、全正 3 题 p = 0.25、全零 p = 1、无题为空；Holm 在 (0.025, 0.05) 两个都显著、(0.0251, 0.03) 都不显著、(0.01, 0.0501) 只第一个、相等取前者、缺一个 p；自助法常数差退化为点、单题、两题 {0, 1} 取到 [0, 1]、宽度与正态理论相符。
- 次要判据：做成率与得分分开；时间位置含 F 为空的题；后半段差奇偶；最简 agent 只有一遍、缺部分题、完全没有。
- 设计灵敏度：合并方差的分子分母；F 为空与只有一遍的题不计入 v；只有一遍时 v 为空；τ² 只依赖方差（整体平移 d 不变）且夹到 0；第 3 遍降低比例在 τ² = 0、v/2、正好一成、全零时的取值；预算端点 B = C3 时补、差 0.01 元不补；最简 agent 未跑时须给预留；取两效应中降低较多者；推送格整体加分不改变判定。
- 校准规则：做成率 9/30、21/30 留下，8/30、22/30 越界；两遍相差正好 20 个点不注明；花费在 519.9、520.0、520.1、650.0、650.1 元的判定；最简 agent 的峰值与轮数不计入 3.3、3.4；每步预算的取整、下限、撞临时上限与封顶；记忆上限的取整（正好整千不上抬）、夹紧、两遍相差正好一倍与超过一倍、中间缺步、退用字节；复盘上限的取整与下限、撞临时上限、没有复盘。
- 读入与命令行：条件映射、非题步与未知条件丢弃、撕裂行、多文件后者为准；正式跑与校准命令各对同一输入跑两次，report.md 与 result.json 逐字节相同；只有一遍时不做第 3 遍判定。
