### 施工中发现并修正

S1 首次转绿运行里，yolo 正常收尾的 Run 被报成"未知"：冷物化的分类结果是 null（正常），而汇总函数用空值合并运算把 null 也当成缺失落进了"未知"默认桶。改为只有物化结果里找不到该 Run 时才落"未知"，两条断言 `failure === null` 的用例由此转绿。
