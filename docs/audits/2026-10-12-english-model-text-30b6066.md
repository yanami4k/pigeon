# 系统提示的框定与面向模型的文字改英文（决策 427–430）审计

基线 30b6066。提交：0e78855、95c46bf（决策）；61c403c（系统提示与换模型重建）；619e0ce（跨层共用的标记）；1541b94、bcdfe42（状态块、通知、提醒、裁剪占位、拒绝理由、worker 与脚本执行器的文字）；1b8a905（工具层，合并 a71a28a）；d13dbd1 至 2398556（联网、Skill、记忆、MCP 与编排类工具，合并 528dfa5）；724c5ef、085b0f5、378034d（收尾与测试）；a23d96d（文档）。

## 一、改了什么

### 系统提示（决策 427、429、430）

- 新增 `src/application/system-prompt.ts`：系统提示的固定底座为英文，分三块——开头一句（"You are Pigeon, a coding agent powered by the <模型> model"，及读文件、跑命令、改代码、写文件、跑一下验证）、Guidelines（看退出码与失败先查清；用 read_file、grep、glob 而不用 shell 的 cat、grep、find；先读后改，write_file 只用于新文件或整体重写；后台作业不轮询、收尾前收齐；简洁、用使用者的语言回答）、Tools（原有的工具用法照译）；末尾接任务指令与开工状态块的说明。各条只写本会话实际有的工具。
- 模型名取本次的模型信息（`promptModelName`）：身份只有启动参数的占位标签 `custom` 时省掉"powered by"半句。
- 续跑：会话记录里最后一个 Run 的开始条目带模型信息时，与本次模型（服务商与 id）不同即按新模型重建系统提示（`sameModelIdentity`）；相同或旧记录没有模型信息时照旧逐字节沿用。主会话续跑（`session-runtime.ts`）与 worker 续做（`workers.ts`）两条路径都接上。
- 开工状态块的权威层级说明改英文；428 之前的中文那句保留为 `STATUS_AUTHORITY_SENTENCE_ZH`，续跑旧会话时据此认出旧系统提示已带说明，不另加旧会话的提示句。

### 面向模型的文字改英文（决策 428）

- 范围：系统提示；工具说明与参数说明；开工状态块与状态更新（节名、引导句、各节正文、"现在没有……"）；工具结果与报错（含容器执行端、工作目录快照、worker 改动叠回）；给模型的通知（后台作业、打转提醒、worker、脚本）与续接补递说明；钩子与审批闸的拒绝理由缺省说法；上下文裁剪与拒收图片的占位；编排层交回模型的报错与说明；会话检索结果里的工具输出来历。
- 不改的：给人看的界面、提示与报错（终端界面、命令行、审批面板、启动与配置报错、消息区的叫停与压缩提示、trace 与回放输出）；只在程序内部用的报错；落盘的数据格式（记忆条目的来源尾巴与文件头、来源取值、配置键）；解析使用者输入的中文（如"额度"）。
- 人和模型都看的文字按给模型的口径用英文：工具结果在终端界面里随之显示为英文；take_worker 与 /take、任务清单与 /tasks 共用的文字同样为英文。
- 参数摘要（`summarizeArgs`）与"没带进来的文件"清单（`skippedFilesText`）两头都用，加 `english` 开关：给模型的地方用英文，给人看的照旧中文。

### 程序认回自己写出的文字（耦合点）

- 写的地方用英文，认的地方新旧两种都认（旧会话记录里是中文），各有测试钉住：
  - run_command 结果里文件变化一段的开头：`src/state/model-markers.ts` 的 `FILE_CHANGES_HEAD`，上下文裁剪按 `lastFileChangesAt` 截取。
  - 程序通知的前缀（打转提醒、worker、脚本）：回看历史按新旧前缀认成系统行。
  - 审批闸无审批通道时的固定拒绝理由：会话判读按新旧两种认出策略拒绝；`governance.ts` 改为直接用这个常量（此前是另写的同一句字面量）。
  - worker 完成通知末行的会话标记：续接时判断是否已递出，新旧两种都认。
- 开工状态块的节名直接改为英文（不在内部名与显示名之间转换）；会话记录里各节哈希的键随之为英文。续跑 428 之前的旧会话：旧的中文节名认不出、按没发过处理，第一次各节整段追加一次，之后照常只追加变了的节（有测试）。
- 会话检索缓存的格式版本 3 → 4（工具输出来历里的"出错""退出码 N"改英文，旧缓存整体重建）；推送记忆的文字版本 v3 → v4。
- 脚本收回被跳过的原因直接取英文句子写进汇总（不落盘，没有中英映射表）。

### 与分岔点回放核对过的原文的差别

- 回放时命令结果还是中文，系统提示退出码那条带"(退出码)"括注；结果改英文（`Exit code: N`）后去掉了这个括注。其余逐字相同（`system-prompt.test.ts` 逐字钉住 TB 实验的装配下的全文）。

### 裁剪占位的长度

- 占位改英文后按字符估算的 token 数变大（估算按约 4 字符 1 token，对中文偏低）。占位已尽量写短；很小的过时读取（约 50 token）不再划算裁掉，相应用例的读取改为 100 token，测的仍是"过时读取不论大小都算"。
