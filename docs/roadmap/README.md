# Pigeon 路线图目录

主路线图位于 [`ROADMAP.md`](ROADMAP.md)；已落定设计索引位于 [`decisions.md`](decisions.md)（按裁决顺序编号，结论、理由与代码锚点；路线图写机制与约束，索引写裁决与理由，两边互指、事实只写一处）；上游 reuse/own 审计表位于 [`m0-reuse-own-audit.md`](m0-reuse-own-audit.md)。

## 阅读约定

- `事实`：来自当前锁定的 Pi 公开 API、源码笔记或已运行证据。
- `设计`：Pigeon 的目标约束，尚未由实现和测试证明。
- `待验证`：需要在 Adapter 纵向切片中通过测试确认的行为。

## 文档目录规范（decisions.md 047）

| 目录 | 内容 | 入库 |
|---|---|---|
| `docs/roadmap/` | 路线图、已落定设计索引、上游 reuse/own 审计表 | 是 |
| `docs/decisions/` | 每次裁决的事实、选项、权衡与结论 | 是 |
| `docs/audits/` | 审计发现、修复过程与验证证据（测试计数、变异变红、真实链路验收）；只追加不覆盖 | 是 |
| `docs/spikes/` | 上游行为探针的实跑笔记；脚本在仓库根 `spikes/` | 是 |
| `docs/notes/` | 会话交接状态、学习材料、上游源码注释 | 否（本地） |

入库文档的写作口径：只写事实、选项、权衡、裁决与证据；不逐字引用对话，不写对人或其他 agent 工作的评价；不含本地绝对路径与任何密钥。

## 维护约定

- 任何技术裁决在项目负责人裁决后，同一次提交内必须同步 `decisions.md`：新增一条或修订既有条目。只写 `docs/decisions/` 不更新索引，视为未完成。
