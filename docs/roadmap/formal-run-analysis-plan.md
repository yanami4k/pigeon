# 正式跑分析计划（预注册）

本文写定正式跑的主判据算法、检验方法、报告措辞与校准各项的取值规则，于校准试跑开始之前入库（decisions 226）。入库之后的改动只能在文末以带日期的修订行追加，且须在看到正式跑结果之前；报告引用本文入库时的提交号。

立场：研究型项目，负结果照实报告；小样本不下变好变差的结论；基线触顶时写"未测出改善（基线触顶）"，不写"证伪"。

## 0 实验设置

- **仓库与题目**：strands 的 89 道题按时间接成一条流（216）。每一步从人在该步之前的代码开工，只让记忆随步数积累（193）。
- **条件**：记忆的 2 × 2——能否检索历史会话 × 有无推送记忆，四格均带验证门与 3 轮回炉（193）；另有最简 agent 作外部参照，不进主判据（194）。记号：00 都没有，01 只能检索，10 只推送，11 推加拉，M 最简 agent。
- **模型与设置**：DeepSeek V4.1 Flash（模型名 deepseek-flash），经本地网关接入；全部条件关思考、温度 0、单次输出上限 16384（203、234）。上下文压缩用产品缺省阈值（218）。
- **推送记忆**：推送两格每步开工时把记忆整份推入系统提示，干活的 agent 带记忆工具，每步收尾与上下文压缩前各复盘一次，复盘指令为模板 v1（191、192、207、217、221）；每遍从空记忆开始，记忆在一遍之内随步积累。
- **题面**：提交信息加应通过的测试名单，名单分两段（198、213、239）；缺省给测试文件路径，按第 5.1 节的难度关可切为给用例名。
- **遍数**：四格各两遍，按第 5.7 节的规则可补第 3 遍；最简 agent 一遍（200、224）。每遍从空记忆开始。
- **预算**：模型费上限 ¥650，不含服务器（200）。
- 记号：题 i = 1…n 按时间顺序；遍 r = 1…R；y(c, i, r) 为格子 c 在第 r 遍第 i 题的部分得分，取值 0 到 1，报告时换成百分点。

## 1 每一步的计量

- **两类用例**（214）：把人在该步的测试分别放到人该步之前、之后的代码上各跑两遍。之前没有通过、之后两遍都通过的为"要做到的"（F）；前后四遍都通过的为"不许挂的"（P）；任一侧两遍结果不同的用例排除，单独计数。
- **部分得分**（201）：y = F 中在 agent 代码上通过的条数 ÷ F 的条数。判题时收集失败的测试文件，其中属于 F 的用例全部算未通过。
- **F 为空的步**：照常跑，记忆照常积累，但不进主判据的分母；报告单列这类步的数目与题号。
- **作废重做**：基础设施故障按跑批器规则作废重做的步，以重做结果为准；重做到上限仍失败、最终缺失的记为缺失（见 2.2）。

## 2 主判据

### 2.1 推送效果与检索效果

先把多遍合起来：ȳ(c, i) = y(c, i, r) 在该格已跑各遍上的平均，各遍等权。对每道有效题 i：

- 推送差 dP(i) = [ȳ(10, i) + ȳ(11, i)] / 2 − [ȳ(00, i) + ȳ(01, i)] / 2
- 检索差 dS(i) = [ȳ(01, i) + ȳ(11, i)] / 2 − [ȳ(00, i) + ȳ(10, i)] / 2
- 交互 dPS(i) = [ȳ(11, i) − ȳ(10, i)] − [ȳ(01, i) − ȳ(00, i)]（次要判据）

效应估计：DP = dP(i) 在全部有效题上的平均，DS 同理，每道题等权。两个主判据并列（199）。

### 2.2 有效题与缺失

- 有效题：F 不为空，且四格在该题上各至少有一遍有效结果。某格某遍在该题缺失的，按该格其余遍的平均计。
- 四格里任一格在该题一遍有效结果都没有的，该题不进主判据，报告列出题号与原因。
- 缺失题超过有效题的 10% 时，报告置顶注明，结论降格为"探索性"。

### 2.3 检验

- **主检验**（222）：按题配对的符号翻转置换检验。零假设下每个 dP(i) 的正负号可以互换，随机翻转 100,000 次；p = （翻转后平均差的绝对值不小于实测的次数 + 1）÷（翻转次数 + 1）。检索差同法。
- **双侧**（255），总误报率 5%，按 Holm 两步校正两个主判据（199）：较小的 p 值 ≤ 0.025 则该效应显著并进入第二步，否则两者都不显著；第二步较大的 p 值 ≤ 0.05 则该效应也显著。
- **置信区间**：按题自助法，题目有放回重抽 10,000 次，每次重算 DP（或 DS），取 2.5% 与 97.5% 分位数。
- **稳健性对照**（222）：线性混合模型 y ~ 推 + 拉 + 推 × 拉 + (1｜题) + (1｜流)，"流"为格 × 遍。与主检验方向或显著性不一致时，报告写明"结论对建模方式敏感"。模型不收敛时不做这项比较，报告注明，主结论照主检验。
- **效应量**：主报 DP、DS 的百分点数与置信区间；附配对标准化效应 dz = mean(d) ÷ sd(d)；另报相对提升 = 主效应 ÷ 对应对照两格的平均得分。
- 置换与自助法的随机种子事先写定，附在分析代码里。

### 2.4 设计灵敏度

报告写明本设计能以 80% 把握分辨的最小效果 MDE：用正式跑自己的数据，MDE = 3.08 × sd(d) ÷ √n，sd 为各题差的标准差，n 为有效题数。3.08 = 2.24（Holm 第一步的双侧 2.5%）+ 0.84（80% 把握）。开跑前的推算见第 5.7 节。

## 3 次要判据与解读顺序

次要判据只作佐证，不单独下结论；p 值不做多重校正，一律标"探索性"（199）。

| 次要判据 | 算法 |
|---|---|
| 做成与否 | 做成 = F 全部通过且 P 无一失败。每格做成率为各有效步做成的平均；推、拉两个效应照 2.1 的方法、把 y 换成做成与否来算，给置信区间 |
| 不许挂一类的失败 | 每步 P 中失败的条数。报每格合计、每步平均、有失败的步数；推、拉效应同 2.1 |
| 学习曲线 | 用差而不用原始得分，以消去题目难度随时间的漂移：把 dP(i) 对题的时间位置 t(i)（按全部 89 道题的时间顺序，第 1 题记 0、最后一题记 1）做最小二乘回归，得斜率；后半段差 = 后一半有效题 dP 的平均 − 前一半的平均，有效题为奇数时去掉正中一题。检索同理。另画四格各自原始得分的滑动平均曲线（窗口 9 题）作描述 |
| 交互效应 | dPS(i) 的平均，置信区间同 2.3 |
| 效率 | 每步轮数、输入 token（命中与未命中）、输出 token、墙钟、花费，干活与复盘分开记。报各格中位数与 90 分位；推、拉效应按题配对取差的中位数 |
| 各格对最简 agent | 每格对 M 的差 = ȳ(c, i) − y(M, i, 1) 在有效题上的平均，置信区间用 2.3 的按题自助法；注明 M 只有一遍、区间偏宽 |
| 记忆使用 | 推送两格：每步复盘结束后记忆的条数与字符数（最后一步即一遍结束值）；每步由干活的 agent 与由复盘写入的新增、改写、删除次数；写满被拒次数；干活的 agent 在回复里标出记忆编号（"依据 [L编号]"）的次数与涉及的条目数，另以读取记忆所引用文件的次数作旁证。检索两格：每步两件检索工具的调用次数与命中会话数 |

解读顺序：
1. 先看两个主效应（Holm）。
2. 某个主效应显著，再看它的学习曲线：斜率为正、后半段差为正，支持"效果随积累而来"；斜率接近零而整体差为正，更像开局就有的效果。
3. 做成与否、不许挂一类的失败，用来核对"部分做对"有没有变成"整体可用"，以及有没有以弄坏旧功能为代价。
4. 效率与记忆使用只用来解释机制，不用来改写结论。
5. 主效应不显著时，次要判据上的差别只报方向与区间，不写"改善"。

## 4 报告的固定措辞

- **测出（显著且为正）**："在 n 道题、R 遍下，推送记忆使每步要做到的用例通过比例平均提高 X 个百分点（95% 置信区间 [a, b]；按题配对的符号翻转检验，Holm 校正后显著，p = …）。"检索同理。
- **测出（显著且为负）**："……平均降低 X 个百分点（……）。"照实写，不找有利的解释。
- **未测出**："在 n 道题、R 遍下，未测出推送记忆的改善：估计差 X 个百分点（95% 置信区间 [a, b]）。本设计能以 80% 把握分辨的最小效果约为 M 个百分点，因此不能排除小于约 M 个百分点的效果。"不写"没用""证伪"。
- **基线触顶**（256）：按各效应自己的对照组判——推送效应看不带推送的两格（00、01），检索效应看不能检索的两格（00、10）；对照组的平均部分得分 ≥ 90% 时，在该效应的结论后加"（基线触顶）"。
- **结论对建模敏感**：主检验与混合模型不一致时，加一句"结论对建模方式敏感，见稳健性分析"。
- **次要判据**：一律写"探索性"，只报方向与区间。

## 5 校准试跑与取值规则

校准的设置（202、219、225）：

- 格子：01 与 11，每格把同一组 15 道题按时间顺序整份跑两遍，每遍从空记忆开始，共 60 步；最简 agent 在同一组 15 道题上跑 1 遍，与两格并行。
- 抽题：先算好全部 89 道题的两类用例，从 F 不为空的题里以 Python 的 random.Random(20260927).sample 抽 15 道，再按时间排序。
- 校准结果不进正式结论。以下规则只看点估计与方差，不看任何格子之间的效果差。

### 5.1 难度关（257）

- 计量：01 格两遍、15 道题的部分得分平均（F 为空的步不计入）。
- 30% ≤ 平均部分得分 ≤ 80%：留在 strands。> 80%：按 197 换仓。< 30%：切为给用例名，只把 01 格在同 15 道题上再跑两遍复测；落进 30%–80% 即以用例名题面开跑，仍低于 30% 交项目负责人另定。端点算在区间内，只看点估计。
- 两遍平均部分得分相差超过 20 个百分点时照样按合计判，报告注明重跑波动大。做成率照常计算，作描述，不参与去留。

### 5.2 花费与能跑几遍（200、258）

- 计量：网关按官方现价逐请求计的花费（含高峰与非高峰），分格、分步记，复盘花费单列。
- 推算：一遍四格 C_pass = 89 × [2 × c01 + 2 × c11] × 1.1，其中 c01、c11 为校准中两格的每步平均花费（含复盘），00 按 01、10 按 11 估，1.1 为记忆变长与后段题更难的余量；最简 agent 一遍 C_M = 89 × cM × 1.1；保底计划 C_base = 2 × C_pass + C_M。校准若大部分在高峰时段，按实测高峰与非高峰价折回非高峰价估算。
- C_base ≤ ¥520：按计划开跑。¥520 < C_base ≤ ¥650：开跑，事先说明第 3 遍基本无望。C_base > ¥650：不自动删减条件或改跑法，交项目负责人裁决，候选（加预算、只在非高峰跑、最简 agent 不跑）列入报告。
- 账单核对（235）：校准后以 DeepSeek 控制台账单核对一次网关计费，差异超过 5% 先查明再开正式跑。

### 5.3 上下文峰值（218）

- 计量：每步各请求送进模型的输入 token（命中加未命中）的最大值。
- 只报分布（中位、90 分位、最大），不用来定阈值；压缩阈值用产品缺省（窗口减预留）。任何一步超过压缩触发点的 80% 时报告项目负责人。

### 5.4 每步宽上限（171、259）

- 校准时取 300 轮、60 分钟（含验证门与回炉，不含复盘）。结果行记每步是否撞上限。
- 校准中没有一步撞上限，正式跑维持；有任何一步撞了，正式取 600 轮、120 分钟并在报告里注明。只上调不下调。

### 5.5 记忆总量上限（191、223）

- 校准时临时取 12,000 字符（按码点计，只计条目）。
- 计量：11 格两遍中每步开工时 MEMORY.md 的字符数，求每步平均增长。
- 正式上限 = 每步平均增长 × 30，向上取整到 1,000，限制在 2,200 到 12,000 字符之间。两遍增长速度相差超过一倍时取较快的一遍。

### 5.6 复盘上限（243）

- 校准时取 40 轮、15 分钟，不占每步宽上限，压缩前复盘同用。结果行记每次复盘是否撞上限。
- 校准中没有复盘撞上限，正式跑维持；有则正式取 80 轮、30 分钟并在报告里注明。只上调不下调。

### 5.7 重跑波动、设计灵敏度与第 3 遍（200、201、219、224）

- **重跑波动 v**：01、11 两格各自按题算两遍得分之差 e(c, i) 的方差的一半，再对两格取简单平均。
- **效果因题而异 τ²**：d(i) = ȳ(11, i) − ȳ(01, i)（各两遍平均）的样本方差 s² ≈ τ² + v，τ² 的估计 = max(0, s² − v)。只用 d(i) 的方差，不用其均值。
- **开跑前推算的 MDE**：SE = √((τ² + v / R) ÷ n)，MDE = 3.08 × SE × 1.3；n 取正式跑的有效题数，1.3 为余量（15 道题的记忆轨迹比 89 道短，同一条流里还有连带影响）。按 R = 2、R = 3 各算一个，写进报告的设计灵敏度一节。
- **第 3 遍**（224）：四格跑完两遍后，剩余预算 B = ¥650 − 已花（含最简 agent，未跑则按 C_M 预留），第 3 遍预计花费 C3 = 前两遍四格的实际平均每遍花费 × 1.1。B ≥ C3，且以两遍数据推算第 3 遍能把 MDE 降低至少一成，才补。推算：v 取四格各自按题两遍之差的方差的一半、再对四格取简单平均，τ² = max(0, 两遍平均的 dP(i) 的样本方差 − v/2)，降低比例 = 1 − √((τ² + v/3) ÷ (τ² + v/2))；检索差同法，取降低较多者。只用方差，不看 dP 的均值。
