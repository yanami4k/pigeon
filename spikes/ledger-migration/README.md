# 账本重构的对照工具（决策 180 / 187 / 206）

账本重构按新旧双写、分段迁移施工。本目录放两类对照工具，只用于验证，产品不读旧格式。

## 双写对照：compare-dual-write.ts

同一次运行在双写期间有新旧两份记录。对照逻辑在 `src/persistence/dual-write-compare.ts`：用只读读取器读新存储，用现有物化读旧账本，逐项比对后输出差异清单。

```
node spikes/ledger-migration/compare-dual-write.ts <治理根> [会话号...] [--no-thinking]
```

当前覆盖：

- 消息：条数、顺序、角色、所属 Run 与 Run 内序号。正文按旧账本自己的抽取口径（同样的 64 KiB 截断与思考持久化选项）处理新存储里的完整消息，重算的内容哈希须与旧条目回指的哈希逐字一致。
- Run 开始：Run 的先后；模型、策略、广告工具、任务指令、常驻记忆与技能清单、MCP 摘要、验证配置、失败重试次数、预算、回炉轮数逐项相等；系统提示全文按旧记录的系统提示哈希核对。
- Run 收尾：有无收尾；结束方式由旧账本的收尾事件、撞上限记录、熔断记录与末轮停止原因推出后比对；消息条数。
- 验证记录：条数、顺序，以及对象会话与 Run、结论、退出码、命令、输出哈希、超时、工作区、各步结论。

分支会话的新文件开头是由 pi 的 fork 从来源复制来的历史，旧账本的分支会话从空开始；对照时跳过复制段（以旧账本里该分支自己的第一个 Run 为界）。代码快照、worker、分叉、授权四类留待改读对应读者时补上。

## 旧转新转换器：convert-legacy.ts

把一个旧会话（事件文件加正文文件）转成新格式的会话文件。它只依赖旧代码里一直存在的模块（物化、正文读取、会话树的消息投影）与上游 JsonlSessionRepo，放进只读旧版工作树（455d88d）里照样能跑；新条目的形状按 `src/state/session-entries.ts` 的 v1 schema 内联写出。

```
node spikes/ledger-migration/convert-legacy.ts <旧会话目录> <会话号> <输出会话根> [--cwd <工作目录>]
```

`sample.ts` 在当前代码上跑通一条样例：用假模型跑一次带思考、工具调用、代码快照、验证与失败分叉重试的运行，得到双写的新文件；再把同一次运行的旧账本转成新格式，按新 schema 校验，与双写的新文件逐条比对并按下面的清单归类。清单外的差异以非零退出码报出。

```
node spikes/ledger-migration/sample.ts
```

### 转换结果与双写新文件的预期差异

1. 正文截断：旧正文文件里单块超过 64 KiB 的文本与思考块是截断后的（带全文哈希），转换出的消息只有截断后的内容；双写存完整消息。
2. 思考签名：旧正文不存思考块签名，转换出的思考块没有签名；运行时关了思考持久化或思考块被上游编辑过的，转换结果里整块缺失。
3. api：旧账本不记助手消息的 api，转换结果一律为 unknown；provider 与 model 取自该 Run 的 run.started。
4. 图片：旧正文只存图片的类型与字节数，转换结果是一段占位文字，用户消息与工具结果里的图片块变成文本块。
5. 用量、停止原因与错误文本：转换结果按 Run 内次序取自 turn.completed；该轮没有收尾记录时用零用量与 stop。
6. 工具调用参数：转换结果取自 tool.proposed 的参数（旧正文的工具调用块只存编号与名字）。
7. 工具结果的 details：旧正文不存，转换结果没有这个字段。
8. 时间：新文件里每个条目的时间戳由存储在写入时盖章，转换结果是转换时刻；消息内部的时间戳两边一致；Run 开始、收尾等条目数据里的时刻，转换结果取旧记录的落盘时刻，与双写时的取值差几毫秒。
9. 条目号：转换结果的消息条目号沿用旧账本的 EntryId，双写为新生成的号；分叉条目里的分叉点条目号随之不同。
10. Run 开始的系统提示：旧账本每个运行面只存一次系统提示全文，转换时之后的 Run 沿用最近一次；旧记录没有全文时为空串。
11. Run 收尾：结束方式按旧记录推出，推不出空回复异常结束；旧账本没有 run.ended 的 Run 不写收尾。
12. 分支会话：转换结果只含旧账本里分支会话自己的记录，不含从来源复制来的历史。
13. 旧 run.started 的这一步起点与结构化记忆字段、worker 派出记录的 taskKey、收尾结果里的 receiptIds 与 structured 不转（新存储也不写）。

样例（假模型，无图片、无大块正文、无思考签名）里实际出现的只有第 7、8、9 三类。
